# 关于本站

KYM Commons 是面向匡院学习共同体的资料站，帮助大家查找课程资料、分享学习经验，并长期维护这些内容。

## 资料怎么组织

- “基础课程” 收录前三学期基础课程资料。
- “各方向资料”按方向整理课程资料。
- 每个方向的 “方向通用资料” 收录不属于某一门课程的学习资源。

课程页可以按类别查看资料，也可以在 [找资料](/browse) 中按关键词、分类和学期查找。

## 如何补充资料

在 [分享资料](/submit) 中选好课程或方向，写几句介绍，上传文件或提供稳定的 HTTPS 链接。找不到合适的方向或课程时，也可以申请新建。

维护者会检查内容、版权和个人信息，审核通过并发布后，资料会出现在对应课程或方向中。

请先阅读 [投稿规则](rules.md)。
